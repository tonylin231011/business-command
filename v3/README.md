# 《外卖大战：雨夜决断》——电影化叙事互动游戏（V3 纵向样片）

[**打开 V3 网页**](https://tonylin231011.github.io/business-command/v3/) · [源代码](https://github.com/tonylin231011/business-command/tree/main/v3) · [原来的 V4 项目](../)

## 这次为什么重做

之前的 V2 是经营面板外加问答卡片：程序跑通，但缺乏故事、表演和电影语言。本版彻底舍弃先做指标的路线，先做一章**能独立游玩的电影叙事**。这不是修补 V2 界面，也不覆盖旧版代码。

## 你会玩到什么
- **2018年冷开场**：一份95亿美元隐含企业价值的交易协议（史实），虚构的董事会场景与对白（明确标注）；
- **倒叙至2013年**：雨夜创业办公室，三个虚构角色围绕校园竞争、现金与履约产生冲突；
- **问话与调查**：3名有立场的NPC，每人2个追问；3份档案。要听至少2条答复并打开2份档案才能签批；
- **拍板**：A守住校园/B双线试探/C快速扩张，均有风险；
- **三种不同的结局镜头**：分别反馈取舍、后果和应继续验证的假设，并与可核对的历史并列呈现；
- **电影化UI**：原创SVG场景美术、暗部光影、镜头缓慢推进、逐句字幕、画面遮幅、可选轻量声音、响应式手机布局；
- **本地数据**：进度保存在浏览器localStorage；结尾可导出JSON。无帐号/网络API/云端。

## 事实与创作的边界

**历史事实**
- 美团外卖于2013年11月上线，最初从高校做起，而非绕开高校直接包抄；
- 2018年4月2日，阿里宣布收购其尚未持有的饿了么股权，交易隐含企业价值**95亿美元**，不是95亿美元全部新增现金或创始人个人所得。

参考文献：
1. [人民网：2015年王慧文采访，确认美团由高校起步，后来开拓白领](https://it.people.com.cn/n/2015/1125/c1009-27852941.html)。
2. [阿里巴巴集团2018年4月2日原始公告](https://www.alibabagroup.com/en-US/document-1491593349923078144)。
3. [美国SEC留存的阿里2018年公告](https://www.sec.gov/Archives/edgar/data/1577552/000110465918021637/a18-9422_1ex99d1.htm)。

**教学虚构**
- 会议室、雨夜、人物“林悦/陈默/周骁”及全部台词、三份战略方案与三种替代结局均为原创虚构；
- 经营指标初始值、选择导致的变化均为无量纲反馈，不是饿了么真实财务数据，也不是历史反事实的预测；
- 没有任何‘和张旭豪一样选即得满分’的评分逻辑。

## 设计约束与不足

当前是**一幕完整的纵向样片**，而非四幕完整版：先验证“开场5分钟真的好看、好玩、故事有悬念”，再依据体验扩充2015补贴与履约、2016战略融资、2018收购。请勿在宣传中称四幕全部完成。

- 音效为浏览器 Web Audio 生成的原创短提示音，须用户主动开启；
- 场景为原创程序化矢量舞台，不含真实人物肖像、未购买商用电影素材；
- 未提供AI自由NPC对话，所有文本为预编排；
- 电脑/手机实际视觉、性能、无障碍与剧情平衡需持续检查；目前没有正式发布审计。

## 运行与验证

无需依赖。用本地静态服务器打开 `v3/index.html`，例如：

```sh
python3 -m http.server 8000
node --check v3/game.js
node v3/smoke.cjs
```

浏览器访问 `http://localhost:8000/v3/`。V3 不覆盖原站 `index.html`，不改旧版进度键值。

## 成功标准

让玩家记住雨声、桌上的协议、角色的争论，以及自己那道命令的代价。不能只因为 Node 测试通过就认定产品成功；必须再做真实用户观感评审和手机端验收。
