# 经营者 · 外卖大战 V2（独立开发线）

[体验 V2](https://tonylin231011.github.io/business-command/v2/) · [原版主页](https://tonylin231011.github.io/business-command/)

此目录是基于独立产品设计的新实验，不覆盖仓库现有 `index.html`、`game.js` 或《千团大战》剧本。**尚未宣布正式发布**。游戏以 2014 / 2015 / 2016 / 2018 四个关键阶段组织剧情；每幕 NPC 为虚构教学角色，玩家可调查情报、选择主战略、调整行动资源、记录依据和止损条件。提交后经营状态持续进入后续剧情。浏览器本地存档，并可导出 JSON。

## 原则
- **史实**：有独立链接来源、可被复核；当事人采访的追溯性观点并非必然客观事实。
- **教学推演**：每幕3项策略的效果、资源点数、四个经营状态均为人为设定的**无量纲模型**。不代表饿了么真实经营值，不作为真实反事实预测。
- **NPC**：林舟、许岚、陈澈、顾远均为虚构人物；对白为原创教学设计，不是历史采访原话。
- **评价**：不按是否与张旭豪选择一致给分。文本理由保存，不假装自动AI评分；四次把握度不足以统计校准。

## 模型规则（透明而非黑箱）
初始状态：现金安全64、市场地位51、履约能力43、战略自主权85，范围各0—100。

每幕先选一个具有增减值的主策略（数值定义在 `game.js` 的 `SCENES[].options`），再分配合计100点的增长G、履约D、储备R。默认 G40 / D35 / R25；每次10点。资源分配额外影响如下，所有结果四舍五入并限制在0—100：

```text
现金安全 = 先前现金 + 主策略现金影响 + round((R-25)*0.24 - (G-40)*0.13)
市场地位 = 先前市场 + 主策略市场影响 + round((G-40)*0.20)
履约能力 = 先前履约 + 主策略履约影响 + round((D-35)*0.19)
战略自主权 = 先前控制 + 主策略控制影响 + round((R-25)*0.04)
```

预算点数代表优先级，而不是千万元、百分比利润、订单数。策略效果均是主观构造的教学参数，不能作为专业经营模型外推。部分策略进入条件由 `options[].requirements` 的现金/控制权阈值决定，第一幕不同选择因此影响第三幕和第四幕可用路线。

## 运行与测试
无需 npm 依赖。GitHub Pages 可直接打开 `v2/index.html`；本地用简单HTTP静态服务。运行：

```bash
node --check v2/game.js
node v2/smoke.cjs
```

真实浏览器的触屏、窗口缩放、localStorage失效、离线字体回退和所有分支仍应人工/自动端到端验收。开源发布前还需要补齐这些验证。

## 当前限制
- 这是第一版独立可玩原型，不是已完成发布审计的精品正式版；
- 场景图是代码绘制的矢量插画，未采用需额外授权的网络人物肖像；
- NPC预设对话，不是假装自由AI聊天；
- 没有后端、跨设备云同步、智能文字评分；
- 可以复制文本战报，但没有正式的小红书分享图片；
- 用户输入不会上传服务器，GitHub Pages托管方访问日志另计。
