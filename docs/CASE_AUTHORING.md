# 真实案例互动编写规范

1. 档案先行：案例ID、角色、时点、已知/未知、来源、证据等级。保留事实与解释的区别。
2. 角色有诉求：每个NPC代表具体利益与信息视角；角色观点不能代替已核实事实。
3. 追问有增量：第一问呈现处境，第二问暴露假设或限制，原始材料入口供核对。笔记只能取已展示的回答。
4. 决策有代价：三条路线都应具体、有吸引力、有损失；不把选中的历史路线写得明显更合理。
5. 揭晓有依据：先展示真实动作，再说明有来源的主张、机制推断与未知。不编造逐项排除路线的当事人心理。
6. 反馈回应理由：路线反馈只是检验问题；自由文字未评估就不能宣称指出了用户的真实错误。
7. 历史有时间：当幕不展示未来数字。后续按历史前进，不假装是玩家选择生成的真实世界后果。
8. 留下可迁移动作：经营投入对应到现实中的小额试验，最终只留一个改进动作。

本集27条NPC入口不等于27次独立研究。第三入口保留原始已编资料，前两入口为基于资料设计的角色问答。
