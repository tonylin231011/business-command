# 48小时公开项目实验

2026-11-08，项目方向正式确定为《经营者》：让真实商业案例可以进入、调查、决策和复盘。已有V3内容作为起点，V4补游戏交互与发布基础。

## 本轮验收范围

- 一集三幕完整可玩；NPC追问、证据笔记、独立签批、逐幕讲评、幕间推进。
- 原创视觉与窄屏布局；离线运行与旧答卷兼容。
- MIT许可、内容来源说明、贡献指南、构建脚本和自动状态检查。
- 公开网站与代码对应；准备宣传稿，用户验收后自行决定发布。

## 48小时阶段

| 阶段 | 交付 |
|---|---|
| 第一阶段 | 完整首集与核心互动，收敛范围 |
| 第二阶段 | 桌面/窄屏流程、备份与离线文件检查，修复实际缺陷 |
| 第三阶段 | 少量真实玩家试用；记录卡住点、完成情况与复盘所得 |
| 第四阶段 | 根据反馈修正，整理演示与发布说明 |

不以填满token预算衡量成功。当前环境无法读取所有平台账单，不宣称1000元预算已经使用或建立扣款。后续付费API和外部花费需有实际授权及可核对账单。

## 成功证据

陌生用户不经口头讲解能进入首幕；能说清自己为什么决策；能在揭晓后指出一个保留或修正的假设。尚未收集的真实试用结果不能写成已通过。
